Currency Converter (Конвертер валют)

Автор: Аделя Яруллина

Дата сдачи: 27.04.2026

Описание программы: Currency Converter — это графическое приложение (GUI) для конвертации валют в реальном времени. Программа получает актуальные курсы обмена через внешнее API, сохраняет историю всех конвертаций в JSON файл и позволяет просматривать предыдущие операции. Приложение решает проблему быстрого пересчета сумм в разных валютах с автоматическим сохранением истории для отслеживания операций. Основные возможности: конвертация между 17 популярными валютами (USD, EUR, RUB, GBP, JPY и др.), получение актуальных курсов из API exchangerate-api.com, сохранение истории всех конвертаций в JSON файл, автоматическая загрузка истории при запуске, проверка корректности ввода (только положительные числа), таблица истории с датой/временем, суммой и курсом, очистка истории с подтверждением, проверка соединения с API, русскоязычный интерфейс.

Требования для запуска: Python 3.10 или выше. Дополнительных библиотек не требуется, программа использует только встроенные модули: tkinter, json, os, datetime, urllib.

Как получить API-ключ: Для работы программы не требуется API-ключ. Используется бесплатный API сервис exchangerate-api.com, который предоставляет до 1500 запросов в месяц бесплатно, курсы обмена для 160+ валют и обновление курсов каждые 24 часа. Если вы хотите использовать свой API-ключ для увеличения лимита запросов: перейдите на сайт https://www.exchangerate-api.com, нажмите "Get Free API Key", введите email и подтвердите регистрацию, затем скопируйте полученный API-ключ и замените в коде URL на: https://v6.exchangerate-api.com/v6/YOUR_API_KEY/latest/{base_currency}.

Как запустить: Клонирование репозитория - git clone https://github.com/твой-логин/currency-converter.git, затем cd currency-converter, потом python main.py. Или просто запустите файл main.py командой python main.py, либо дважды кликните по файлу main.py в проводнике Windows.

Примеры использования: Тест 1 - Базовая конвертация: конвертировать 100 USD в RUB. Ожидаемый результат - получение суммы в рублях по текущему курсу. Фактический результат - 100 USD = сумма в RUB по текущему курсу. Статус: Успешно. Тест 2 - Проверка на отрицательное число: ввести сумму -50 USD. Ожидаемый результат - сообщение об ошибке "Сумма должна быть положительной". Фактический результат - программа показывает сообщение об ошибке и не выполняет конвертацию. Статус: Успешно. Тест 3 - Сохранение истории: выполнить несколько конвертаций, закрыть и снова открыть программу. Ожидаемый результат - все предыдущие конвертации отображаются в таблице истории. Фактический результат - история загружается из JSON файла и отображается корректно. Статус: Успешно.
